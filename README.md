# The Burrow

Early-2000s nostalgia with a point. The Burrow is an interactive 2000s desktop holding sourced GRC write-ups on the bills, court cases, and incidents shaping surveillance and privacy. Each write-up has source list.

All write-ups are original work. The desktop design is inspired by early-2000s operating systems. No affiliation with or endorsement by any company exists or is implied.

**Live site:** [burrow.wichman.io](https://burrow.wichman.io)

Built with HTML, CSS, and JavaScript. Hosted on GitHub Pages.
